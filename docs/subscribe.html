RSS 聚合头条

iPhone 上没有内置的 RSS 阅读器，所以订阅要借任意一个阅读器 App 完成。 下面两条路二选一，第一条通常一步就完事。

办法一：直接交给阅读器 App

点下面这个按钮，系统会跳到你 iPhone 上已装的 RSS 阅读器并带上这份订阅地址。 适用于 NetNewsWire、Reeder、Follow 等支持 feed:// 的 App。
用阅读器打开并订阅
没反应＝你还没装这类 App，或者它没有认这个协议，那就走办法二。

办法二：复制地址，粘贴到阅读器里

这条地址任何阅读器都认（包括 Inoreader、Feedly、阅读、Follow 的网页端）。

https://cheney-hub.github.io/rss-hub/feed.xml

复制上面的订阅地址
  • 打开你的阅读器 → 「添加订阅 / Add Feed」
  • 长按输入框 → 粘贴 → 保存
  • 还没装 App？在 App Store 里搜「RSS 阅读器」，免费的 NetNewsWire 就够用

你会收到什么

多源国际中文媒体合并去重后的最新 120 条，正文全文不截断（每源最多取 5 条）； 白天约每 5 分钟重建一版，受 GitHub 定时器兑现率所限实际约 1~3 小时一版。 另有专供墨水屏的设备版（每 5 分钟换一条），见首页。
